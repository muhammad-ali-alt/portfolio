## The question

Where in the US should Intel put a new data center, based on how the electricity grid actually behaves?

## The data

About **549,000 rows** of hourly US electricity grid data.

## What I built

A Tableau dashboard with **7 visualizations** and a time period parameter, so the same views can be compared across different time ranges.

## Result

The analysis recommended the **Northwest region**.
